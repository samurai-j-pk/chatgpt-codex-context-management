# ChatGPT & Codex Context Management

Draft diagrams that map how ChatGPT Chat/Work and Codex assemble context for a response or action. They are intended as a community-reviewable explanation of the visible product behaviour and the boundaries that OpenAI has not documented.

## Diagrams

- `diagrams/chat-work-context.mmd` — ChatGPT Chat and Work context map
- `diagrams/codex-context.mmd` — Codex context map

## Review request

Please review for accuracy, especially where the diagrams distinguish documented behaviour from unknown or undocumented behaviour. Suggestions and corrections are welcome through pull-request comments.

## Background

This project is maintained by a CFO and knowledge worker working in renewables and energy trading. It explores how a generalist who rarely codes can adopt developer-style methods in AI operations.

Its specific purpose is to map and understand use cases for ChatGPT Chat/Work compared with Codex, including what choosing one or the other means for memory and context management.

## Scope

This repository contains only the diagram sources and this explanatory README. It does not include private chat transcripts, account data, or local files.
